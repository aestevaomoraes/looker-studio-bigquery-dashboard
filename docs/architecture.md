# Cloud Architecture

This project uses a modern cloud-based analytics architecture.

## Data Flow

Raw Data → BigQuery → SQL Views → Looker Studio → Dashboard

## Components

### Google BigQuery

Used as the analytical data warehouse layer.

Responsibilities:

- Data storage
- SQL transformations
- Business rules
- Analytical views

### Looker Studio

Used as the visualization and dashboard layer.

Responsibilities:

- KPI visualization
- Interactive filters
- Charts and tables
- User interaction

## Benefits

- Fully cloud-native
- Scalable analytics
- Fast SQL queries
- Professional dashboard design
- Low infrastructure cost
